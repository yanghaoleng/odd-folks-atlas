# 自部署运行

需要 Node.js 22 或更新版本，无需 npm install，无运行时第三方依赖。源文件直接放在 `dist/` 和 `service/`，没有构建步骤。内部 HTTP 路由仅服务同源编辑器，不是受支持的对外 API 或 SDK。

## 本地完整体验

```sh
npm run dev
```

打开 http://127.0.0.1:4180 。此命令明确开启本地无密码开发编辑，支持素材调整、定义修改与 PNG 上传，数据保存在 `data/`。不能用 localhost 替代该地址，也不要通过隧道、反向代理或端口转发暴露开发模式。开发模式拒绝公开监听地址、非本机 Host、跨来源写入和 `NODE_ENV=production`。

## 默认只读部署

```sh
npm start
```

默认仅监听 127.0.0.1:4180，所有写入关闭；仍可浏览、预览、下载图片。由部署者选择 HTTPS 反向代理和访问控制。只需代理此监听端口，不要暴露项目根目录或数据目录。

可用环境变量：

- `PORT`：监听端口，默认 4180。
- `HOST`：默认 127.0.0.1。仅只读模式允许修改监听地址。
- `ATLAS_DATA_DIR`：专用持久化目录，默认项目中的 data；必须在 dist 外。
- `ATLAS_ORIGIN`：公开 HTTPS 同源地址，仅用于非开发部署。不要包含路径。
- `ATLAS_AUTH_DIR`：部署者自行初始化的私有认证目录；启用前请阅读 LOGIN.md。

需要远程编辑时，按 [配置自己的管理员登录](LOGIN.md) 由部署者在自己的终端设置管理 PIN，并配置 HTTPS 同源地址和私有认证目录。没有默认密码，也没有连接作者部署的凭据。未配置认证时始终只读。不要将开发模式暴露到公网。

## 数据和恢复

首次启动从当前发行版的默认配置创建空白数据，绝不读取既有托管站点数据。独立清单版本为 `odd-folks-atlas-v1`，不会执行其他站点的历史数据迁移。已有定义数据与清单不匹配或损坏时启动失败，不会静默重置。

配置、定义和上传文件保存在独立子目录。正常关闭用 Ctrl+C 或 SIGTERM；单个数据目录只允许一个写入进程。历史配置在各子目录的 versions 中保留。备份应在停机后复制整个 data 目录。硬终止后可能留有 writer.lock，必须先确认没有进程仍在使用该目录，再由部署者处理。不要把数据目录提交到 Git 或放入公开静态目录。

## 验证

```sh
npm test
```

测试使用临时目录和随机 loopback 端口，覆盖首次启动、只读访问、显式本地编辑、跨源拒绝、Host 校验、写入重启持久化、素材哈希、并发版本控制和配置校验；不连接托管站点、不创建生产认证凭据。
